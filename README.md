# ALNTECH CELL

MVP web para reunir a apresentação da ALNTECH CELL, um catálogo de produtos e um fluxo inicial de assistência técnica.

## Funcionalidades

- Site institucional com serviços, diferenciais e chamadas para contato.
- Catálogo com busca, categorias, carrinho e resumo de compra demonstrativo.
- Painel de assistência para abrir ordens de serviço, consultar status e avançar etapas.
- Layout responsivo para celular e desktop.

## Executar

Abra `index.html` em um navegador. O projeto não exige instalação nem dependências externas.

## Limites deste MVP

Os produtos e preços são exemplos. Ordens, carrinho e preferências ficam no `localStorage` do navegador atual. Não há servidor, autenticação, sincronização entre dispositivos, integração com WhatsApp, estoque real ou processamento de pagamentos. Antes de uso comercial, conectar um backend e revisar dados, preços, contatos e políticas da empresa.

## Estrutura

- `index.html`: conteúdo e áreas da aplicação.
- `styles.css`: identidade visual e responsividade.
- `app.js`: navegação, catálogo, carrinho e fluxo de ordens de serviço.
